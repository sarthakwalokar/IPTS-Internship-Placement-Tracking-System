📌 Internship Placement Tracking System
📖 Description

This project is designed to manage and track student internships and placement records efficiently. It allows students and admins to handle placement-related data in an organized way.

🚀 Features
🔐 Student Login & Registration
🧑‍💼 Admin Dashboard
📊 Add / Update Internship Details
🏢 Placement Tracking
📋 View Reports
🛠️ Technologies Used
Java (Servlets & JSP)
JDBC
MySQL
HTML, CSS

▶️ How to Run
Clone the repository
Import project into Eclipse
Configure database (MySQL)
Run on Apache Tomcat server
Open in browser
🗄️ Database
Student Table
Internship Table
Placement Table
🔮 Future Scope
📧 Email Notifications
🏢 Company Portal Integration
